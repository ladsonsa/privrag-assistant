
# PrivRAG Assistant

A local-first Retrieval-Augmented Generation (RAG) application for
question answering over privacy-related PDF documents.

The project is designed both as a functional application and as a
portfolio project demonstrating software engineering, RAG architecture,
document processing, automated testing, and local AI integration.

## Overview

PrivRAG Assistant allows users to ask questions about indexed privacy-related
documents.

The application processes PDF documents, extracts their text, generates
embeddings, stores document information in a vector database, and retrieves
relevant context to support answers generated by a local Large Language Model
(LLM).

The system uses Retrieval-Augmented Generation rather than fine-tuning the LLM
with the documents.

## Architecture

The initial application follows a modular monolith architecture.

Main components:

- React + TypeScript frontend
- FastAPI backend
- Application service layer
- PDF processing with PyMuPDF
- ChromaDB vector storage
- Ollama for local LLM and embedding execution
- Docker Compose for local infrastructure
- Automated testing with Pytest
- Code quality checks with Ruff

The backend is organized into separate modules with focused
responsibilities, while remaining part of a single application.

## Setup

### 1. Clone the repository

```bash
git clone <repository-url>
cd privrag-assistant
```

### 2. Install dependencies

```bash
uv sync
```

### 3. Configure environment variables

Create a local `.env` file based on the example configuration:

```bash
cp .env.example .env
```

Review the values in `.env` before running the application.

The `.env` file must not be committed to Git.

## Running the Backend

Run the FastAPI application with:

```bash
uv run uvicorn backend.app.main:app --reload
```

The API should be available at:

```text
http://127.0.0.1:8000
```

FastAPI interactive documentation:

```text
http://127.0.0.1:8000/docs
```

## Health Check
